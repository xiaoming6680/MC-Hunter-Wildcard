# 猎人游戏 - 外卡系统（Hunter Wildcard）

一个用于 Minecraft Manhunt / 猎人追逃玩法的 Fabric 模组。

玩家分为 **猎人（Hunter）** 和 **逃亡者（Runner）**，在对局过程中系统会周期性抽取“外卡事件”，改变局势节奏，让每一局都有不同玩法体验。

---

## ✨ 核心特点

### 🎮 对局系统
- 支持猎人 vs 逃亡者阵营玩法
- 管理员控制对局开始与结束
- 提供准备阶段，避免开局混战

### 🧭 追踪机制
- 猎人获得追踪指南针
- 目标位置按配置周期刷新

### 🎴 外卡系统（核心玩法）
- 对局过程中周期性抽取随机外卡
- 外卡效果会通过 HUD / BossBar / 提示信息展示
- 支持节奏变化型玩法（增强随机性与策略性）

### 🧠 胜利条件
支持多种胜利方式：
- 击败末影龙
- 存活指定时间
- 到达指定坐标
- 收集指定物品
- 淘汰所有敌对玩家

### ♻️ 复活系统
- 可配置复活规则
- 支持：
  - 不复活模式
  - 有限生命
  - 无限复活
- 可分别设置猎人 / 逃亡者规则

### ⚙️ 配置系统
- 默认按 `H` 打开配置界面
- OP 可在等待阶段修改规则
- 支持服务端配置文件同步

## 🎴 外卡列表

| 外卡 | 效果 |
|------|------|
| 疾速追猎 | 全员速度提升 |
| 轻盈之身 | 跳跃提升 + 缓降 |
| 全员发光 | 所有玩家发光 |
| 暗夜追猎 | 强制夜晚 + 猎人夜视 |
| 死亡爆炸 | 死亡或击杀触发爆炸 |
| 补给空投 | 生成随机补给箱 |
| 猎人雷达 | 显示目标距离提示 |
| 指南针干扰 | 追踪方向偏移 |
| 饥饿追逐 | 饥饿加快，进食节奏变化 |
| 武器过热 | 连续攻击触发过热 |
| 轻装上阵 | 轻甲加速，重甲减速 |
| 方块腐化 | 方块延迟消失 |
| 珍珠狂潮 | 定期补给末影珍珠 |
| 风弹乱斗 | 定期补给风弹 |
| 血怒时刻 | 低血量强化 |
| 暂时停用 | 本轮无效果（节奏占位） |

## 🧩 环境要求

- Minecraft 1.21.11
- Fabric Loader 0.19.0+
- Fabric API
- Java 21

建议客户端与服务端同时安装。

---

## 📦 安装方式

1. 安装 Fabric Loader
2. 安装 Fabric API
3. 下载 mod jar 文件
4. 放入 `mods/` 文件夹
5. 启动游戏 / 服务端

首次启动会生成配置文件：config/hunterwildcard.json

---

## 💬 玩家命令

| 命令 | 说明 |
|------|------|
| `/hw join hunter` | 加入猎人 |
| `/hw join runner` | 加入逃亡者 |
| `/hw leave` | 离开队伍 |
| `/hw status` | 查看状态 |
| `/hw wildcard list` | 查看外卡状态 |

---

## 🛠 管理员命令

（需要 OP 权限）

| 命令 | 说明 |
|------|------|
| `/hw start` | 开始对局 |
| `/hw stop` | 停止对局 |
| `/hw wildcard roll` | 立即抽取外卡 |
| `/hw wildcard stop` | 停止当前外卡 |
| `/hw config reload` | 重新加载配置 |
| `/hw config save` | 保存配置 |
| `/hw ts true` | 开启调试界面 |
| `/hw ts false` | 关闭调试界面 |

---

## ⚙️ 配置说明

按 `H` 打开配置界面，可调整：

- 游戏状态
- 队伍与规则
- 外卡系统
- 胜利条件
- 复活规则

---

## 📌 设计目标

本模组设计目标是：

- 保持对局节奏变化
- 增强随机性与策略性
- 提供可配置的 Manhunt 玩法扩展
