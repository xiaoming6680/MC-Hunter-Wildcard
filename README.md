# 猎影外卡 (Hunter Wildcard)

一个用于 Minecraft Manhunt / 猎人追逃玩法的 Fabric 模组。玩家分为猎人和逃亡者，在追猎过程中会周期性抽取外卡事件，让每一局都出现不同的节奏变化和临场策略。


## 功能特色

- 队伍玩法：玩家可加入猎人或逃亡者阵营，管理员统一开始和停止对局。
- 准备阶段：开局前提供准备时间，可限制猎人准备区域，避免提前追击。
- 追踪指南针：猎人获得追踪指南针，系统会按配置刷新逃亡者位置。
- 轮换外卡：对局运行后按间隔随机抽取外卡，并通过 HUD、BossBar 和提示信息展示。
- 多种胜利条件：逃亡者可通过击败末影龙、存活指定时间、到达坐标或收集物品获胜；猎人可通过淘汰逃亡者或累计击杀获胜。
- 复活规则：支持不复活、有限生命、无限复活，并可分别配置猎人和逃亡者。
- 配置界面：默认按 `H` 打开客户端配置面板，OP 可在等待阶段编辑规则并同步到服务端。
- 配置文件：服务端会生成 `config/hunterwildcard.json`，也可以手动编辑后重载。

## 外卡列表

| 外卡 | 效果 |
| --- | --- |
| 疾速追猎 | 全员获得速度提升。 |
| 轻盈之身 | 提供跳跃提升和缓降效果。 |
| 全员发光 | 所有参赛玩家进入发光状态。 |
| 暗夜追猎 | 强制入夜，并给予猎人夜视。 |
| 死亡爆炸 | 玩家死亡或击杀相关事件触发爆炸。 |
| 补给空投 | 在场上生成随机补给箱。 |
| 猎人雷达 | 猎人定期获得最近逃亡者的距离提示。 |
| 指南针干扰 | 猎人指南针目标产生偏移。 |
| 饥饿追逐 | 玩家更容易饥饿，进食后获得追击节奏变化。 |
| 武器过热 | 连续攻击会积累过热状态。 |
| 轻装上阵 | 轻甲获得速度优势，重甲受到速度惩罚。 |
| 方块腐化 | 新放置的方块会在一段时间后消失。 |
| 珍珠狂潮 | 定期补给末影珍珠。 |
| 风弹乱斗 | 定期补给风弹。 |
| 血怒时刻 | 低血量玩家获得强化。 |
| 暂时停用 | 本轮外卡不产生额外效果，用于节奏缓冲。 |

## 环境要求

- Minecraft `1.21.11`
- Fabric Loader `0.19.0` 或更高版本
- Fabric API
- Java `21`

建议服务端和所有玩家客户端都安装本模组。只安装服务端时，命令和服务端逻辑可以运行，但客户端菜单、HUD 外卡动画和按键入口无法完整显示。

## 安装

1. 安装对应 Minecraft 版本的 Fabric Loader。
2. 安装 Fabric API。
3. 从 GitHub Releases 下载 `hunter-wildcard-1.0.0.jar`。
4. 将 jar 放入服务端和客户端的 `mods` 文件夹。
5. 启动游戏或服务端，首次启动后会生成 `config/hunterwildcard.json`。

## 基本用法

### 玩家命令

| 命令 | 说明 |
| --- | --- |
| `/hw join hunter` | 加入猎人阵营。 |
| `/hw join runner` | 加入逃亡者阵营。 |
| `/hw leave` | 离开当前阵营。 |
| `/hw status` | 查看当前对局状态。 |
| `/hw wildcard list` | 查看外卡启用状态。 |

### 管理员命令

以下命令需要至少 OP 2 级权限：

| 命令 | 说明 |
| --- | --- |
| `/hw start` | 开始对局并进入准备阶段。 |
| `/hw stop` | 停止当前对局并清理状态。 |
| `/hw wildcard roll` | 在 RUNNING 阶段立即抽取一个外卡。 |
| `/hw wildcard stop` | 停止当前外卡。 |
| `/hw config reload` | 从 `config/hunterwildcard.json` 重新读取配置。 |
| `/hw config save` | 保存当前配置到配置文件。 |
| `/hw ts true` | 为当前 OP 打开调试页面。 |
| `/hw ts false` | 关闭当前 OP 的调试页面。 |

## 配置说明

默认按 `H` 打开“猎人外卡”配置界面。配置面板包含：

- 游戏状态：查看当前状态、身份、双方人数和外卡倒计时。
- 队伍管理：加入猎人、加入逃亡者或离开队伍。
- 基础规则：设置准备时间、结算时间、指南针刷新、猎人准备区域和死亡掉落。
- 胜利规则：设置逃亡者和猎人的胜利方式。
- 生命复活：设置双方复活模式、生命数和复活时间。
- 外卡规则：设置外卡间隔、持续时间、启用状态和具体外卡参数。
- 调试操作：开启 `/hw ts true` 后可用于测试外卡和调试对局。

服务端配置文件路径：

```text
config/hunterwildcard.json
```

配置只能在等待阶段安全编辑。对局开始后，部分配置会被锁定，避免中途修改导致状态不一致。

## 从源码构建

Windows PowerShell：

```powershell
.\gradlew.bat build
```

构建产物位于：

```text
build/libs/hunter-wildcard-1.0.0.jar
```
